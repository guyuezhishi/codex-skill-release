# Codex Skill Release

A reusable Codex Skill for reviewing, packaging, and publishing Codex Skills to GitHub.

## Contents

- `codex-skill-release/SKILL.md` — the skill instructions.
- `codex-skill-release/references/release-checklist.md` — detailed review and release checks.
- `codex-skill-release/agents/openai.yaml` — UI metadata for the skill.

## Install

Copy the `codex-skill-release` folder into your Codex skills directory, for example `~/.codex/skills/`. Then invoke `$codex-skill-release` when reviewing or publishing a Codex Skill.

This skill does not contain GitHub credentials or grant permission to publish. Confirm the destination and visibility for each release.
